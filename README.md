# Klarwerk

Website der KI‑Akademie Klarwerk: *KI. Klar gemacht.*
Statische Website mit [Astro](https://astro.build), gehostet auf IONOS.

```bash
npm install      # einmalig
npm run dev      # Vorschau auf http://localhost:4321
npm run build    # fertige Website in dist/
```

Jeder Push auf `main` wird automatisch auf IONOS veröffentlicht.
